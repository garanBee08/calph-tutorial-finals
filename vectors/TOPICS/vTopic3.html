Vector Addition and Subtraction

The head-to-tail method of vector addition is the process of putting the second vector's tail on the first vector's head, and then drawing the resultant vector from the first vector's tail to the second vector's head. Vectors can be added using both graphical and analytical methods, with the resultant vector having its magnitude equal to the length of the line segment in drawing, pointing toward the same direction as the diagonal, and its direction as the diagonal from the same origin.

Magnitude and Direction

There are two primary graphical methods:

  • Head-to-tail method — This a technique for adding vectors by placing them end-to-end.
  • Parallelogram method — This is a technique to add two vectors by forming a parallelogram from them.

Head-to-Tail Method

This Figure (i) shows vector addition using the head-to-tail method. The first vector u is drawn, then the second vector v is placed so that its tail starts at the head of u. The resultant vector (u+v) is drawn from the tail of u to the head of v, showing the total effect of both vectors combined.
This picture shows vector subtraction using the head-to-tail method. The first vector u is drawn normally, while the second vector v is reversed in direction to get -v. Then, -v is placed so its tail is at the head of u. The resultant vector (u-v) is drawn from the tail of u to the head of -v, representing the resultant vector that shows the difference between u and v.

Parallelogram Method

This picture uses the parallelogram method to add vectors u and v. Both vectors are drawn from the same origin point. A parallelogram is then completed using these vectors as two adjacent sides. The resultant vector (u+v) is the diagonal of this parallelogram, drawn from the common origin to the opposite corner.
This diagram shows how to subtract vectors using the parallelogram method. Vector u is drawn from the origin, and vector -v (the reverse of v) is also drawn from the origin. A parallelogram is formed with these two vectors. The resultant vector (u-v) is the diagonal from the origin to the opposite corner, showing the difference between u and v.

Analytical Methods

Analytical methods use mathematical calculations instead of drawings to find resultant vectors. These methods provide exact numerical results and are particularly useful for complex vector problems.

Vector (Unit) Resolution: Component or Resolving Vectors into Components

This is the process of breaking down a vector into its horizontal (x-axis) and vertical (y-axis) components. Any vector can be expressed as the sum of two perpendicular component vectors.

This diagram illustrates how vector A is resolved into its x and y components (Ax and Ay). The angle θ shows the direction of the vector from the positive x-axis. Using trigonometry:

Ax = A cos θ (horizontal component)
Ay = A sin θ (vertical component)

Analytical Method Using Trigonometry

This figure shows two vectors A and B at an angle θ to each other. Using trigonometry, we can find the magnitude and direction of their resultant. The law of cosines and law of sines are typically used:

Magnitude: R = √(A² + B² + 2AB cos θ)
Direction: Found using the law of sines

Analytical Method Using Pythagorean Theorem

When two vectors are perpendicular (at 90° to each other), the Pythagorean theorem can be used to find the resultant:

Magnitude: R = √(A² + B²)
Direction: tan θ = B/A

This is a special case that simplifies calculations when vectors are at right angles.

Vector Addition and Subtraction: Subtraction of vectors

Looking into negatives

When subtracting vectors, we are essentially adding the negative of the vector being subtracted. The negative of a vector has the same magnitude but points in the opposite direction.


To subtract vector B from vector A (A - B):

  • Reverse the direction of vector B to get -B
  • Add A and -B using either graphical or analytical methods
  • The result is the vector difference A - B

Numerical/Area Analysis

Example Problem:

Given two vectors:

  • Vector A: magnitude 5 units at 30° from horizontal
  • Vector B: magnitude 3 units at 120° from horizontal

Find: A + B and A - B


Solution using component method:

Step 1: Resolve into components
Ax = 5 cos(30°) = 4.33 units
Ay = 5 sin(30°) = 2.5 units
Bx = 3 cos(120°) = -1.5 units
By = 3 sin(120°) = 2.6 units

Step 2: Add components
Rx = Ax + Bx = 2.83 units
Ry = Ay + By = 5.1 units

Step 3: Find magnitude and direction
R = √(2.83² + 5.1²) = 5.83 units
θ = tan⁻¹(5.1/2.83) = 60.9°

Conclusion

Vector addition and subtraction are fundamental operations in physics and mathematics. The graphical methods (head-to-tail and parallelogram) provide visual understanding, while analytical methods (component resolution, trigonometry, and Pythagorean theorem) give precise numerical results. Mastering both approaches is essential for solving complex physics problems involving forces, velocities, displacements, and other vector quantities. Remember that vector subtraction is simply adding the negative of a vector, and always verify your results by checking both magnitude and direction.
