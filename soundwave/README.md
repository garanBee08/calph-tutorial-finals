# A website focusing in Sound and Waves Topic

A personal web application that helps users **learn from multimedia-rich tutorials** and **explore quizzes**. This project aims to make learning Calculus Based Physics more engaging and accessible for students.

---

## Features

🔐 **Login & Authentication** — Secure sign-up and login system powered by Supabase
📚 **Learn About Sound** — Understand key concepts of sound with multimedia-rich lessons
🌊 **Learn About Waves** — Explore the types, properties, and behavior of waves through visuals
🧠 **Take Quizzes** — Test your knowledge with short quizzes after each lesson
👤 **Profile Page** — Track your progress and quiz scores
