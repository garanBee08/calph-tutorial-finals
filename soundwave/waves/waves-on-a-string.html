WAVES ON A STRING

A wave on a string is a type of mechanical wave that travels along a stretched string when a disturbance (such as plucking or striking) occurs. The disturbance moves through the string as a transverse wave, meaning the particles of the string vibrate up and down, while the wave itself travels horizontally along the string.

STRING WAVE FORMULAS

The speed of a wave on a string increases with greater tension and decreases with higher linear mass density, meaning tighter strings allow faster waves while heavier strings slow them down.

μ

Linear Mass Density

μ = m / L

μ: mass per unit length (kg/m)

m: total mass of the string (kg)

L: length of the string (m)
